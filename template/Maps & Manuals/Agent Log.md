# Agent Log

Two purposes: (1) track structural changes made to the vault so there is an audit trail, (2) log agent errors and misroutes for pattern recognition during [[System/Skills/Workflows/Weekly Review|Weekly Review]].

---

## Section 1: Structural changes

Log any change that affects Maps & Manuals files, YAML conventions, folder structure, bulk edits across multiple notes, or new system-level workflows. Content changes to individual Effort or Atlas notes do not need to be logged here.

**Format:**
```
### YYYY-MM-DD: [Short description]
**Changed:** what files or conventions were modified
**Why:** the reason for the change
**Watch for:** anything that could break or drift as a result
```

**Keep an entry under 120 words.** The length belongs in **Watch for**, which is the only part a future reader cannot reconstruct from the files themselves.
