## Rules

- The Existing notes table is generated from Atlas frontmatter by `System/scripts/build_views.py`; new notes with frontmatter appear automatically.
- Add to the backlog when a topic comes up repeatedly but no note exists yet.
- A backlog entry becomes a real note when there is enough source material or understanding to write it properly. Do not create empty placeholder notes.
- Process sources into Atlas using [[System/Skills/Workflows/Process Source into Atlas|Process Source into Atlas]].
