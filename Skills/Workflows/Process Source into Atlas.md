# Workflow: Process Source into Atlas

Use when raw material from Sources should become reusable, permanent knowledge.

**Destination:** `Ideaverse/Atlas/`

---

## Steps

1. Read the source in full.
2. Extract the ideas, concepts, and frameworks worth keeping.
3. Search existing Atlas notes for related content.
4. If a relevant Atlas note exists: add to it rather than creating a new one.
5. If no relevant note exists: create a new one using the [[System/Skills/Templates/Atlas Note|Atlas Note]] template.
6. Link the new or updated note to related Atlas notes with wikilinks.
7. Add a reference to the source at the bottom of the Atlas note.
8. Keep the original source intact in Sources. Do not delete or overwrite it.
9. Summarize what was created or updated and why.

---

## Atlas note quality check

Before saving, confirm the note:
- Is written in the user's perspective, not copied from the source
- Has a clear one-sentence definition or summary at the top
- Explains why this matters in the user's context
- Links to at least one related note if one exists
