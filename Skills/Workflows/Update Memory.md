# Workflow: Update Memory

Use when something stable has changed about the user, their preferences, or how the vault should work.

**Primary destination:** [[Maps & Manuals/Me|Me]]

---

## Steps

1. Identify exactly what needs to change and in which file.
2. Summarize the proposed change before making it.
3. Edit only the relevant section.
4. Update the "Last updated" date.
5. Confirm what changed and why.

---

## Which file to update

| What changed | Where to update |
|---|---|
| How to work with the user | [[Maps & Manuals/Me\|Me]] |
| Vault structure or routing rules | [[Maps & Manuals/Vault Map\|Vault Map]] |
| Available skills | [[Maps & Manuals/Skill Map\|Skill Map]] |
| Domain knowledge (fraud, career, etc.) | The relevant domain note |

---

## What belongs in Me.md vs elsewhere

**Add to Me.md:** stable working preferences, communication rules, recurring patterns, vault operation rules, long-term goals.

**Do not add to Me.md:** temporary reminders, one-off facts, things that belong in an Effort or Calendar, content that already has a dedicated domain note.

If a section in Me.md has not changed agent behavior in 60 days, move it to a domain note and replace it with a wikilink.
