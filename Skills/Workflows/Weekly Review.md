# Workflow: Weekly Review

Superseded as the maintenance engine by [[System/Skills/Workflows/Weekly Maintenance|Weekly Maintenance]] (agent-run, scheduled Fridays 16:00). This note remains as the manual checklist for the human review step.

**Destination:** `Ideaverse/Calendar/YYYY-WXX - Weekly Review.md`

---

## Steps

### 1. Open and update Current Context
- Read [[Maps & Manuals/Active Context|Active Context]].
- Is the active focus still accurate?
- Are the current priorities still right?
- Update if anything has shifted.

### 2. Review active Efforts
- Open [[Ideaverse/Efforts/Efforts Index|Efforts Index]].
- For each active effort: read the Next Actions section.
- Mark completed actions as done.
- Add new next actions if needed.
- Flag any effort with no movement in 30+ days for archiving.

### 3. Process the Sources inbox
- Open `Ideaverse/Sources/`.
- For anything captured this week: decide its fate.
  - Worth processing into Atlas? → tag it for [[System/Skills/Workflows/Process Source into Atlas|Process Source into Atlas]]
  - Links to an active Effort? → add the connection
  - Not useful? → delete it now, not later
- Aim to leave Sources with nothing unreviewed older than one week.

### 4. Create the weekly note
- Use the [[System/Skills/Workflows/Weekly Review|Weekly Review]] template in `Ideaverse/Calendar/`.
- Fill in: what got done, what did not, what is next week's focus.

### 5. Check the Agent Log
- Open [[Maps & Manuals/Agent Log|Agent Log]].
- If any agent errors or misroutes happened this week, is there a standing fix worth adding to [[Maps & Manuals/Me|Me]] or a domain note?

---

## Time target

30 minutes or less. If it takes longer, the vault has too much unreviewed material. Fix the capture habit, not the review.
